# INFINITY Hair Studio — Demo

Yusuf Acar ve INFINITY Hair Studio erkek bölümü için hazırlanan statik web sitesi demosu.

## Bilgisayarda açma

`index.html` dosyasını Chrome veya Edge ile açın.

## GitHub Pages ile yayınlama

1. GitHub'da yeni ve herkese açık bir repository oluşturun.
2. Bu klasördeki bütün dosyaları repository'nin ana dizinine yükleyin.
3. Repository içinde **Settings → Pages** bölümünü açın.
4. **Deploy from a branch** seçeneğini seçin.
5. Branch olarak `main`, klasör olarak `/ (root)` seçip kaydedin.

GitHub birkaç dakika içinde sitenin bağlantısını oluşturur.

## Gerçek bilgiler geldiğinde

Telefon, WhatsApp, Instagram, çalışma saatleri ve kesin konum bağlantıları `index.html` içinden güncellenebilir. Demo bağlantıları şu anda bilerek pasiftir.

## Dosya yapısı

- `index.html`: sayfa içeriği
- `style.css`: tasarım ve mobil görünüm
- `script.js`: animasyonlar ve etkileşimler
- `media/`: video, fotoğraf, logo ve kaydırma kareleri
